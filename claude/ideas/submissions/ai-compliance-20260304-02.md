# Idea: AI-Generated Artefact Traceability Standard

## 1. Problem Statement

Documents and code produced by Claude Code in this repository are not currently distinguishable from human-authored ones in the commit history or document headers. Commits include a `Co-Authored-By: Claude` trailer, which is a start — but governance documents generated by AI do not carry any metadata indicating their AI origin in the document itself. If an AI-generated spec contains an error, there is no mechanism for systematically identifying all other AI-generated specs that might contain similar errors. This undermines the explainability requirement for AI-produced governance artefacts.

## 2. Strategic Alignment

Section reference: AI Compliance §4.4 — "require explicit documentation of AI impact; ensure historical behaviour changes are traceable"

Alignment rationale: Traceability of AI-generated content is a core AI compliance requirement. The current commit trailer is process-level traceability; document-level traceability means that any reader of a governance document can immediately identify whether it was AI-generated and subject it to appropriate scrutiny. This is an explainability control, not a restriction on AI usage.

## 3. Proposed Solution

Add a `Generated-by` field to the document lifecycle guide's optional header fields: `Generated-by: Claude Code (claude-sonnet-4-6) — <date>`. Require this field in all governance documents authored primarily by an AI agent. For human-authored documents, the field is omitted. Existing documents should be retroactively assessed and the field added where appropriate. Update the AI usage policy (submitted separately) to reference this standard as a mandatory disclosure requirement.

## 4. Expected Value

Enables systematic audit of AI-generated content: any reviewer can search for `Generated-by: Claude` to find all AI-authored documents and assess them for errors, bias, or authority overreach. Measurable as: proportion of AI-generated governance documents with traceability metadata (target: 100% of documents created after the standard is adopted).
