# Idea: Force Explicit Evidence Review for ATR Parameter Selection

## 1. Problem Statement

The 14-day ATR period is documented in §11 as the current production configuration, but no document contains evidence that this value was selected through analysis rather than by convention or default. Every stop calculation — the primary risk management function of the system — depends on this parameter. If it was chosen arbitrarily, the entire risk framework is built on an unvalidated assumption. The governance model requires that rules are "explicit, intentional, and owned" — the current ATR period satisfies "explicit" but not "intentional" (no rationale) and not "owned" (no evidence trail).

## 2. Strategic Alignment

Section reference: §12.3 — Change control requirements ("any parameter change must: state the rationale and expected impact"); §14 — Authority statement ("if a rule can change outcomes, it must be explicit, intentional, and owned")

Alignment rationale: The Challenger's mandate is to force explicit trade-offs and surface hidden assumptions. The ATR period is a hidden assumption: it appears documented but its selection rationale is absent. The governance model requires this gap to be explicitly addressed — either by producing the evidence or by formally acknowledging the parameter was a default choice and documenting that acknowledgement.

## 3. Proposed Solution

Commission a formal review producing a decision record that answers: was the 14-day ATR period chosen through analysis, convention, or default? If through analysis, what was the analysis and where is it documented? If by convention, document this explicitly as the rationale. The outcome is a decision record — not necessarily a parameter change. If the review finds the parameter is suboptimal, it triggers the strategy parameter sensitivity analysis (submitted separately) and a §12.3 change process.

## 4. Expected Value

Closes a governance gap in the strategy rules document. Either produces evidence validating the current parameter (risk reduced, governance satisfied) or triggers a parameter improvement process (potential improvement to risk-adjusted returns). The cost of the review is one sprint task; the cost of not doing it is an undocumented assumption at the core of every stop calculation.

## 5. Effort Estimate

- [x] Small — days to 1 week

Constraints or dependencies: Requires input from the Strategy Owner and potentially historical trade data analysis. If the original parameter selection was informal, the outcome is a documented acknowledgement of that fact — which is itself a valid governance artefact.

## 6. Reversibility

- [x] Fully reversible — no lasting effects

Reasoning: A decision record is documentation; producing it does not change system behaviour.
