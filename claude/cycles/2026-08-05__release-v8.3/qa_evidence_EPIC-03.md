That first pass found and blocked a real defect on ST-11 (and, on re-verification, an identical defect class in ST-12 not originally called out): `DialogContent`/`DialogTitle` className overrides (`p-0 gap-0`, `text-base`) silently losing to the shared `Dialog` primitive's own hardcoded base classes, because this project's `cn()` helper (`src/lib/utils.js`) is plain `clsx` with no `tailwind-merge` de-duplication — confirmed empirically by compiling `tailwind.config.js` directly. Fixed in commit `cae2730b` using Tailwind's `!` important-modifier prefix on the specific overriding utilities; re-verified via a fresh compiled-CSS check and approved on the second pass. No P0 deviation resulted — the defect was caught and corrected before ever being presented as done, not shipped.

**Post-PR-open CI failure and fix (2026-08-06):** after PR #1259 opened, GitHub Actions' real Playwright run (not the sandboxed pre-merge check) failed `SC-CR-11` — `expect(triggerBtn).toBeFocused()` timed out, focus state read "inactive" after Escape. Root cause: the original implementation assumed Radix's `Dialog.Content` would fall back to restoring `document.activeElement` when no explicit `onCloseAutoFocus` handler is supplied — it does not. Radix's actual default tries `context.triggerRef.current?.focus()`, and that ref is only ever populated by an actual `<DialogTrigger>` component (the same root cause `TradePlan.js`'s own Abandon modal already documents for its single trigger — this modal just has two trigger sites, so a single fixed ref doesn't fit that precedent directly). Fixed by capturing `document.activeElement` in a ref on open and restoring it explicitly via `onCloseAutoFocus`, generalising `TradePlan.js`'s single-trigger pattern to this modal's multi-trigger case. Re-verified locally against a real Chromium binary: all 11 `compliance-recheck.spec.js` scenarios pass, including `SC-CR-11`. This is the second real defect this story's Playwright coverage caught before merge — both the sandboxed pre-merge review and this real-CI run earned their keep.
