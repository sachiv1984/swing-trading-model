Type C — Dependency Stall: A gate or pre-condition was invisible, ambiguous, or not enforced

**Recurrence:** No — first appearance. (`2026-09-14__scheduled` used the same structural heuristic without noticing; its lessons learnt did not record this.)

**What happened:**

**Where in the routine:**
STEP 3.1 — Actionable Backlog Assessment (Scale-appropriate methodology, step 2).

**Root cause:** process gap

**Blast radius analysis:**

- When it would have surfaced: never on its own — a lapsed date raises no signal; it stays "T" indefinitely.
- Recovery cost if uncaught: medium (cycle rework — items silently withheld from planning for months; already true for 3 consecutive release plannings).

**Process patch:**

  - Change: after the A/T/D/L split, re-classify any gated item whose latest gate date is ≤ the run date, or whose gate names an already-completed prior item, as "A (date-lapsed — verify)", list it in `run_manifest.md`, and carry the list into the capacity outlook.
